# JP Fitness 5.0

## Actualización en GitHub/Vercel
1. Descomprime este ZIP.
2. En tu repositorio `jp-fitness`, elimina o reemplaza los archivos anteriores con estos.
3. Sube todos los archivos a la raíz del repositorio.
4. Haz `Commit changes`.
5. Vercel usará:
   - Build Command: `npm run build`
   - Output Directory: `dist`
6. Vercel publicará automáticamente la nueva versión.

## Cambios principales
- Rediseño premium negro, azul celeste estilo Lazio y blanco.
- Sin React ni dependencias externas: compilación más estable.
- Entrenamiento guiado ejercicio por ejercicio.
- Cuatro series en todos los ejercicios de fuerza.
- Perfiles separados para Juan Pablo, Juanpita y Constanza.
- Calendario, hábitos, avance, gráficas y respaldos.
- JP Coach local basado en registros.
- Migración automática de datos de versiones anteriores cuando sea posible.
- Ilustraciones animadas, no videos reales.
- La IA generativa requiere un backend seguro y no viene conectada en esta versión.

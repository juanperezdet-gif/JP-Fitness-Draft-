# JP Fitness V6.2 Green Edition — Golden integration

Incluye 30 paquetes Golden (90 archivos WebP) y ocho videos Athletic Flow de la base V6.2.

La aplicación conserva las claves de almacenamiento, IDs de ejercicios y la rutina existente.

Las secuencias se muestran como un ciclo de tres fases (inicio, medio, final) en tarjetas y entrenamiento guiado.

Se reutilizan imágenes cuando el ejercicio coincide con un movimiento existente. Los ejercicios de cardio, movilidad y Athletic Flow conservan su representación anterior.

El ZIP contiene la aplicación completa, lista para extraer en la raíz del repositorio. No borres los registros del navegador ni desinstales la PWA para actualizar.

QA pendiente en dispositivo real: reproducción, secuencias, temporizadores, progreso e historial.
